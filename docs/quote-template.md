# 견적 안내문 템플릿

`docs/company-info.md`의 계좌 정보를 사용한다. 대괄호 항목만 채우면 된다.

```
[로아유 / 사람사랑유학원] [학교명] 최종 견적 안내

[성인/주니어] [N]인 / [코스] [N]주 / [기숙사 타입] 기준

- 유학원 등록금 ₩100,000
- 학비 ([코스] [N]주) ₩[금액]
- 기숙사 ([타입] [N]주) ₩[금액]
- 학교 프로모션 ([조건]) -₩[금액]
- 유학원 최대할인 적용 -₩100,000
--------------------------------
최종 견적: ₩[합계]

▶ 등록 절차
1) 유학원 등록금 ₩100,000 입금 → 입학 신청 진행
2) 학교 인보이스 발행 후 잔금 ₩[합계-100,000] 송금

▶ 등록금 입금 계좌
토스뱅크 1002-6221-6262 (예금주: 로아유)
입금 금액: ₩100,000
입금자명은 신청자 본인 성함으로 부탁드립니다.

※ 학교 프로모션은 [마감일] 등록 마감이므로 그 전에 등록금 입금이 완료되어야 할인 적용이 됩니다.
※ 항공권, 비자연장비, SSP, 현지 납부 비용(전기세·보증금 등)은 별도입니다.
```
